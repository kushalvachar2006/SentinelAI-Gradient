# SentinelAI-Gradient

> AI-Powered Cybersecurity Monitoring & Threat Intelligence Platform



   

Overview

SentinelAI-Gradient is a modern AI-driven cybersecurity dashboard and monitoring platform designed to provide real-time visibility into infrastructure security, suspicious activities, and threat intelligence.

The platform combines a visually rich gradient-based UI with intelligent monitoring capabilities to help users identify, analyze, and respond to cybersecurity threats efficiently.

Whether used for educational purposes, cybersecurity demonstrations, or as a foundation for advanced security tools, SentinelAI-Gradient delivers a clean, scalable, and responsive architecture.

Installation

Prerequisites

Make sure the following tools are installed:

Node.js (v18+ recommended)

npm or yarn

Git



---

Clone the Repository

git clone https://github.com/kushalvachar2006/SentinelAI-Gradient.git
cd SentinelAI-Gradient


---

Install Dependencies

npm install

or

yarn install


---

Run the Development Server

npm run dev


---

Build for Production

npm run build


---

Environment Variables

Create a .env file in the root directory:

VITE_API_URL=your_api_url
VITE_OPENAI_API_KEY=your_api_key

> Modify according to your backend/API configuration.
