## 📌 Overview

**SentinelAI-Gradient** is a modern AI-inspired cybersecurity dashboard designed to visualize security alerts, infrastructure activity, and threat intelligence in a clean and futuristic interface.

The project focuses on:

- Real-time security monitoring concepts
- AI-assisted threat visibility
- Modern SOC dashboard UI/UX
- Infrastructure and asset visualization
- Interactive cybersecurity analytics

This project can be used for:

- Cybersecurity portfolio projects
- SOC dashboard demonstrations
- Security visualization research
- Frontend UI inspiration
- Educational cybersecurity systems

## ⚙️ Installation

### 1️⃣ Clone the Repository

```bash
git clone https://github.com/kushalvachar2006/SentinelAI-Gradient.git
cd SentinelAI-Gradient
```

### 2️⃣ Install Dependencies

```bash
npm install
```

### 3️⃣ Start Development Server

```bash
npm run dev
```

### 4️⃣ Build for Production

```bash
npm run build
```

## 🌐 Environment Variables

Create a `.env` file in the root directory:

```env
VITE_API_URL=your_api_url
VITE_API_KEY=your_api_key
```
